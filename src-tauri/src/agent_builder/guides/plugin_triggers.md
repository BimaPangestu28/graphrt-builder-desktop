- When the job should run on an event from a plugin (a meeting was recorded, a file was added, a message arrived) rather than on a schedule, the person picks that plugin trigger on the agent's Schedule screen ("Also run on an event"); you cannot set it. Each event starts one run with the event's fields as inputs, so the `start` node declares those fields as `text-input` variables (required only for the one the next step needs) and the steps read them as `{{#start.<field>#}}`. Say in your reply which trigger to pick. Never ask the person to type the event fields themselves.
