- When the job needs facts from the person's own documents, menu, price list, FAQ or website (a knowledge base), add a `knowledge-retrieval` step before the model step that answers. Set `query_variable_selector` to the question (e.g. `[start, question]`) and list the knowledge base in `dataset_ids`: its id (`kb_...`) when the request gives one, otherwise its exact name in quotes, e.g. `dataset_ids: ["Catering menu and prices"]`. Never invent a knowledge base the person did not mention.
- Keep `multiple_retrieval_config: { top_k: 4 }` unless the person asks for more or fewer passages. Pass the result to the answering `llm` with `context: { enabled: true, variable_selector: [<retrieval step id>, result] }` and put `{{#context#}}` in its system prompt, telling it to answer only from that context and to say so when the answer is not there.
